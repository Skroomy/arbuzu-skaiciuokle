# arbuzu-skaiciuokle

Python Programavimo Pagrindu modulio semestro projektas.  
Užduotis:  
Sukurkite programą kuri leistų vartotojui pasirinkti norimą patiekalą iš menių sąrašo, kuriame nurodytas patiekalo pavadinimas ir kaina. Taip pat programa turi leisti vartotojui pridėti ir pašalinti pasirinktus patiekalus ir skaičiuoti galutinę sumą. Naudokite Tkinter grafinę sąsają.  
Kodas yra tragiškas, skaityti nerekomenduoju
